# **Jogo do Número Secreto** 
Sejam bem-vindos ao meu primeiro README, garanto que os próximos serão mais bonitos! Lhes apresento um dos meus repositórios com o jogo do número secreto, projeto usado também no curso de Git/GitHub pelo alura.

## Sobre o jogo
O jogo consiste em uma barra de texto onde o jogador terá de enviar chutes, que devem ser escolhidos dentro de uma faixa específica de números. Enquanto o chute for incorreto, o jogo irá instruir com pistas até que o número correto seja chutado!

## Como funciona o sorteio
Um número aleatório dentro de uma faixa determinada (exemplo: 1 a 100) são sorteados a cada rodada através do parseInt(Math.random())
